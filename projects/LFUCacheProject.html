Concrypto (Concurrency cryptography)

Go Generics Data structures LFU cache Linked list Memory optimization

Что сделано

Что сделано

Реализован LFU-кэш на Go с поддержкой операций Get и Put за O(1) без амортизации. В основе реализации используется собственная система frequency buckets для хранения элементов по частоте использования.

Реализован eviction policy по алгоритму LFU (Least Frequently Used) с дополнительным LRU tie-breaking: при одинаковой частоте использования удаляется элемент, который использовался наиболее давно.

В проекте использованы Go generics (K comparable, V any), благодаря чему кэш поддерживает работу с произвольными типами ключей и значений без потери типобезопасности.

Особое внимание уделялось производительности и управлению памятью. Для уменьшения количества аллокаций реализован собственный object pool для переиспользования cache nodes, что позволяет снижать нагрузку на garbage collector при интенсивной работе кэша.

Перемещение элементов между frequency buckets реализовано без создания новых нод: элементы linked list переиспользуются и переносятся между списками через detach/push-механизм, что минимизирует количество дополнительных указателей и операций выделения памяти.

Дополнительно реализован итератор All(), возвращающий элементы в порядке убывания частоты использования. При одинаковой частоте элементы сортируются по принципу most recently used first.
